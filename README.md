# Cyber Security Coursework

## Overview

Cybersecurity coursework focused on penetration testing, vulnerability assessment and network security using vulnerable lab environments.

## Key Areas

* Network scanning and service enumeration using Nmap and enum4linux
* Vulnerability exploitation and Metasploit
* Web application vulnerabilities including SQL injection, XSS, CSRF and command injection
* Cryptographic weaknesses, brute-force and dictionary attacks
* Session hijacking, DoS and social engineering
* Security mitigation and defensive measures

## Tools

* Nmap
* Metasploit
* Wireshark
* Ettercap
* enum4linux
* DVWA / OWASP Vulnerable Machine
